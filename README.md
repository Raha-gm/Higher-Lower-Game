# Higher or Lower Game 🎮

A fun command-line guessing game built with Python.

The player compares two famous people, brands, or organizations and guesses which one has more followers.

## Features

- Random account selection
- Follower count comparison
- Interactive user input
- Score tracking
- ASCII art display
- Continuous gameplay until an incorrect guess

## Technologies Used

- Python
- Random Module
- Functions
- Loops
- Conditional Statements
- Lists and Dictionaries

## Project Structure

```text
Higher-Lower-Game/
├── main.py

├── art.py
└── README.md
```

## How to Play

1. Run `main.py`.
2. Two accounts will appear on the screen.
3. Guess which account has more followers.
4. Type A or B to make your choice.
5. Get one point for each correct answer.
6. The game ends when you make an incorrect guess.

## How to Run

Make sure Python is installed, then run:

```bash
python main.py
```

## Requirements

No external libraries are required.

This project uses Python's built-in `random` module.

## Note

The follower counts are sample values stored in the project and do not represent current statistics.
